# Web Clones — Demo Projects

Four front-end UI clones built by **Ibrahim Khan** for learning and portfolio purposes.
Each is a single self-contained `index.html` — just open it in a browser, no build step needed.

| Project | What works in the demo |
| --- | --- |
| [facebook-clone](facebook-clone/) | News feed, stories row, contacts sidebar, working post composer (your post appears in the feed), like / comment / share buttons, live search filter |
| [amazon-clone](amazon-clone/) | Product grid, category filters, live search, star ratings, working shopping cart (add / remove / quantities / subtotal) and demo checkout |
| [youtube-clone](youtube-clone/) | Video grid, category chips, live search, sidebar subscriptions, in-page video player (real playable sample videos), working like button |
| [netflix-clone](netflix-clone/) | Cinematic hero, scrolling title rows with hover cards, My List (add / remove), live search, details popup with playable trailers |

**Tech:** HTML5 · CSS3 · Vanilla JavaScript — responsive layouts for desktop, tablet and mobile.

> These are educational UI clones. They are not affiliated with Meta, Amazon, Google or Netflix, and use sample images/videos from public placeholder libraries.
