About CricPK

CricPK is a worldwide sports discovery platform built for one simple problem: free, legal live sport exists in almost every country — it's just scattered across dozens of official apps and channels that most fans never find.

CricPK brings those official sources together in one directory: governing-body platforms like ICC.tv, FIFA+ and Watch.Hockey, national free-to-air broadcasters like PTV Sports, 7plus, TVNZ+ and DD Sports, and the official YouTube and radio channels of the world's cricket boards and leagues.

What CricPK will never do: host pirated streams, bypass a subscription or DRM, or label a channel “live” when it isn't. If a sport is paid in your country, the card says so — and points you to the official broadcaster.

How channel changes work now

This public site is a static build, so there is no database to edit yet. To add, remove or correct a channel: tell Muse the change (“add this official channel”, “remove X”, “this link changed”) and the site is updated and redeployed — the same workflow as the Live Cricket site.

Phase two (planned): a Next.js app with a real admin dashboard — login, add/remove channels stored in a database, and scores APIs — hosted on Vercel with API keys kept in server environment variables, never in page code.

In-page playback

19 of the 32 channels now play inside CricPK: Red Bull TV, through its official free HLS live stream, and 18 official YouTube channels through YouTube's own embed player — Sports Central, Pakistan Cricket, BWF TV, Cricket Ireland Live, Rabbitholebd Sports, FIBA, FIFA, ICC, UEFA, Formula 1, Cricbuzz, Sony Sports Network, New Zealand Cricket, ATP, WTA, World Rugby, Volleyball World and Olympics. A channel's Live tab plays only while that channel is actually broadcasting, and its Latest videos tab always works. FIFA+ is the clearest example of the rule: the FIFA+ platform itself forbids embedding (its live matches still open on FIFA+), but FIFA's official YouTube channel permits it — so FIFA videos play here while the page says exactly that. The other 13 channels keep their official-platform button because the broadcaster permits no embedding and has no verified embeddable channel — 7plus and TVNZ+ even block framing outright (X-Frame-Options: SAMEORIGIN). An ordinary web-page link is never treated as a video stream, and nothing is copied, re-hosted or DRM-bypassed. All channel IDs above were read off the broadcasters' own YouTube channel pages on 28 Oct 2026.

Setup & deployment (phase two)

When the backend phase is built, it deploys as a standard Next.js project:

1. Push the project to GitHub and import it in Vercel.
2. Add API keys in Vercel → Project → Settings → Environment Variables
   (server-side only, e.g. SPORTS_API_KEY) — never in client code.
3. Connect the database (e.g. Vercel Postgres / Supabase) for
   channels, favorites and admin users.
4. Deploy. Admins sign in at /admin to add or remove channels;
   changes publish instantly, no redeploy needed.

Scores data plugs in the same way: a server route fetches the licensed sports API with the secret key and serves clean JSON to the pages, so keys are never exposed to visitors.
